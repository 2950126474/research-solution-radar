# 简短试用案例

在新聊天中用自然语言测试，不额外提示技能名称：

| 请求 | 应有行为 |
| --- | --- |
| 当前项目已说明领域和问题，用户说“帮我看看别人是怎么做的” | 简短复述目标并请用户确认；确认后检索，给少量做法及对应原始来源 |
| 用户说“帮我看看有什么好的 idea”，但需求不明确 | 利用上下文给两三个具体方向帮助选择；等待确认后查近期研究，再给建议 |
| 用户已确认研究目标，继续说“就按这个查” | 直接检索，不重复确认 |
| 用户明确说“直接查，不要问我” | 说明必要假设后检索，尊重用户要求 |
| “接下来怎么办？” | 不仅因为这句话就触发本技能，正常处理项目问题 |
| “帮我给生日派对想个好 idea” | 不触发科研或开发文献检索 |
| “离线帮我想研究 idea，不要联网” | 尊重离线要求，明确未核实近期文献，不虚构来源 |
| “详细比较这几种研究方法” | 按要求展开，不机械限制篇幅 |
| 旧主页说结果较好，但最新审计已将其降为探索线索 | 优先采用有证据的修正；可推荐候选方向，但不声称现有数据已足以验证 |

检查用户能否说清别人怎么做、建议借鉴什么，以及对应来源是否支持说法。自然语言选择不保证每次成功；明确调用只能验证执行效果，不能作为自然触发成功的证据。
